# 源码7k-AI数字人分身系统 v1.4.0+v1.3.8独立版 小程序端+H5端+WEB端（uniapp开源端）

源码获取：ym7k.com/18843/

口播短视频、企业宣讲、直播辅助、客服播报的需求持续增长，很多博主、商家、企业都想搭建私有化数字人生成平台，摆脱 SaaS 平台的高额抽成与接口限制。这套 AI 数字人分身系统包含 v1.4.0 与 v1.3.8 两个独立版本，搭配 Uniapp 开源前端，同时覆盖微信小程序、H5、WEB 管理后台，私有化部署、自主可控，是快速搭建数字人内容生产平台的成熟源码方案。

一份工程可编译小程序、H5，WEB 后台独立配套，方便运营人员统一管控任务。源码无加密，支持深度二次开发，UI 界面、交互逻辑、计费规则都可以按需定制，适合贴牌交付、品牌私有化改造。两个版本各有侧重，v1.3.8 版本稳定成熟，BUG 少，适合追求平稳运营；v1.4.0 新增多项优化，任务调度、字幕渲染、素材管理能力升级，可按需选择部署，也可以对比功能进行合并改造。

核心能力围绕数字人分身视频生产打造，支持自定义数字人形象、音色选择、文本驱动生成视频。用户输入旁白文案，选择数字人形象、配音音色、背景图片或背景视频，一键生成数字人口播视频。支持上传自定义形象素材，字幕样式自由调整字体、颜色、位置，支持长文稿自动拆分、批量任务排队生成，非常适合矩阵账号批量产出短视频，适配自媒体、本地商家、讲师、财税法务等行业。

平台内置完善的商业化付费体系，后台灵活配置算力包、时长包、会员套餐，支持按次、按月、按年多种计费模式。对接主流支付渠道，订单、卡密兑换、分销推广功能齐全，用户邀请好友消费可获得返佣，助力平台裂变获客。后台可查看算力消耗明细、视频生成记录、用户数据、任务队列，支持任务优先级调度、失败重试、限流管控，缓解高并发下任务阻塞问题。

风控与素材管理模块齐全，素材库统一管理图片、音频、数字人形象，支持分类归档。配备作品审核、用户内容审核机制，拦截违规文案，降低平台合规风险。权限分级管理，总后台、子账号、代理商权限隔离，支持分站代理模式，方便招商租赁数字人服务。
